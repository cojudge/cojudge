Соберите анаграммы из массива строк.

Вы получаете массив `strs`, держащий строки. Разделите его записи на сборники так, чтобы слова, помещенные в один и тот же сборник, были перестановками друг друга — то есть они делят точно такой же набор букв. Последовательность сборников в вашем ответе не имеет значения.

**Ограничения:**

- `1 ≤ strs.length ≤ 10^4`
- `0 ≤ strs[i].length ≤ 100`
- Каждый `strs[i]` состоит исключительно из строчных английских букв.
