Given two strings `s` and `t`, return the number of distinct subsequences of `s` that
equal `t`.

A subsequence is formed by deleting zero or more characters without changing the
relative order of the remaining characters. The answer is guaranteed to fit in a
signed 32-bit integer.

**Constraints:**
- `1 <= s.length, t.length <= 1000`
- `s` and `t` contain only uppercase and lowercase English letters.
