Разработайте алгоритм, который получает ежедневные цены акции и для текущего дня возвращает размах цены.

Размах — максимальное число последовательных дней, считая от текущего дня назад, в которые цена была не больше сегодняшней.

Например, если цены предыдущих четырёх дней равны `[7,2,1,2]`, а сегодняшняя цена равна `2`, размах равен `4`: это сегодняшний день и три предыдущих дня с ценами `2,1,2`. Если предыдущие цены равны `[7,34,1,2]`, а сегодня цена равна `8`, размах равен `3`.

Реализуйте класс `StockSpanner`:

- `StockSpanner()` создаёт объект.
- `int next(int price)` принимает сегодняшнюю цену `price` и возвращает её размах.

Используйте имя класса `StockSpanner`; имя `Solution` зарезервировано проверяющей системой. Конструктор и метод соответствуют оригиналу.

Проверка детерминированная: каждый результат `next` точно сравнивается с эталонной моделью на основе монотонного стека.

**Пример 1:**
```
Вход: operations = ["StockSpanner","next","next","next","next","next","next","next"], values = [[],[100],[80],[60],[70],[60],[75],[85]]
Выход: [null,1,1,1,2,1,4,6]
```
Пояснение: Размах считает последовательные дни назад с ценой не выше текущей. День 4 с ценой 70 охватывает 60 и 70: размах 2. День 6 с ценой 75 охватывает 60, 70, 60, 75: размах 4. День 7 с ценой 85 охватывает все дни, кроме первого с ценой 100: размах 6.

**Пример 2:**
```
Вход: operations = ["StockSpanner","next","next","next","next","next","next"], values = [[],[10],[4],[5],[90],[120],[80]]
Выход: [null,1,1,2,4,5,1]
```
Пояснение: Цена 5 охватывает дни с ценами 4 и 5; цена 90 — все дни до неё включительно; цена 120 — также все предшествующие дни и текущий. Цена 80 охватывает только текущий день.

**Пример 3:**
```
Вход: operations = ["StockSpanner","next","next","next"], values = [[],[30],[20],[10]]
Выход: [null,1,1,1]
```
Пояснение: Цены строго убывают, поэтому размах каждого дня равен 1.

**Ограничения:**
- `1 <= price <= 10^5`
- Не более `10^4` вызовов `next`.
