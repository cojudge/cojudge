Вам дается первый узел `head` отдельно связанного списка, узлы которого хранят целое число.

Для каждой соседней пары в текущей цепи сплайсируйте свежий узел, расположенный между ними, чье сохраненное значение равно наибольшему общему делителю значений двух соседей.

Возвращайте голову цепи, как только все вставки будут завершены.

Напомним, что наибольшим общим делителем пары является наибольшее положительное целое число, разделяющее оба значения без остатка.

**Ограничения:**

- Количество узлов в списке находится в диапазоне `[1, 5000]`.
- `1 <= Node.val <= 1000`
