The Hamming distance between two integers is the number of bit positions at which their binary representations differ.

You are given two non-negative integers `x` and `y`. Return their Hamming distance.

**Example 1:**
```
Input: x = 1, y = 4
Output: 2
Explanation: 1 is 0001 and 4 is 0100 in binary, which differ in the lowest and third bits.
```

**Example 2:**
```
Input: x = 3, y = 1
Output: 1
Explanation: 3 is 0011 and 1 is 0001, differing only in the second bit.
```

**Constraints:**
- `0 <= x, y <= 2^31 - 1`
