`RandomizedCollection` хранит мультимножество чисел: одинаковые значения могут встречаться несколько раз. Структура должна поддерживать вставку, удаление и получение случайного элемента.

Реализуйте класс `RandomizedCollection`:

- `RandomizedCollection()` создаёт пустую коллекцию.
- `bool insert(int val)` добавляет `val`, даже если такое значение уже есть. Возвращает `true`, если до вставки значения не было, иначе `false`.
- `bool remove(int val)` удаляет одно вхождение `val`, если оно есть. Возвращает `true`, если вхождение найдено и удалено, иначе `false`.
- `int getRandom()` возвращает случайный элемент. Вероятность выбора значения пропорциональна числу его вхождений. Гарантируется, что при вызове коллекция не пуста.

Каждый метод должен работать в среднем за O(1).

Используйте имя класса `RandomizedCollection`; имя `Solution` зарезервировано проверяющей системой. Конструктор и методы соответствуют оригиналу.

Проверка: результаты `insert` и `remove` точно сравниваются с эталонной моделью, хранящей число вхождений. Результат каждого `getRandom` должен присутствовать в коллекции на момент вызова. Распределение статистически не проверяется.

**Пример 1:**
```
Вход: operations = ["RandomizedCollection","insert","insert","insert"], values = [[],[1],[1],[2]]
Выход: [null,true,false,true]
```
Пояснение: Первая вставка 1 возвращает true, повторная вставка 1 — false. Вставка нового значения 2 возвращает true.

**Пример 2:**
```
Вход: operations = ["RandomizedCollection","insert","insert","remove","remove"], values = [[],[2],[2],[2],[2]]
Выход: [null,true,false,true,true]
```
Пояснение: После двух вставок числа 2 каждый remove удаляет одно вхождение. После первого удаления остаётся одно, после второго — ни одного.

**Пример 3:**
```
Вход: operations = ["RandomizedCollection","insert","getRandom"], values = [[],[9],[]]
Выход: [null,true,9]
```
Пояснение: В коллекции находится только 9, поэтому getRandom должен вернуть 9.

**Ограничения:**
- `-2^31 <= val <= 2^31 - 1`
- Не более `2 * 10^5` вызовов `insert`, `remove` и `getRandom`.
- `getRandom` вызывается только для непустой коллекции.
