Заполните сетку 9x9 Sudoku так, чтобы каждая строка, каждый столбец и каждый из девяти подкоробок 3x3 содержали цифры `1` через `9` ровно один раз. Пустые ячейки записаны как `'.'`; предварительно заполненные цифры должны оставаться нетронутыми.

Каждая доска пропускается в виде девяти строк из девяти символов, и вы должны вернуть заполненную доску в той же форме: девять строк с каждой `'.'` заменены правильной цифрой.

**Ограничения:**
- `board.length == 9`
- `board[i].length == 9`
- Каждая ячейка содержит цифру `'1'`-`'9'` или `'.'`.
- Каждая тестовая доска признает по крайней мере одно действительное завершение.

*Примечание по адаптации: * классическое утверждение редактирует `char[][]` на месте без обратного значения. Поскольку этот судья сравнивает возвращенные значения, каждая строка кодируется как строка, и вы возвращаете девять завершенных строк строк.
