Целый массив `coins` перечисляет доступные номинальные значения токенов, в то время как целое число `amount` указывает денежную сумму для сборки.
Выберите набор, взятый из `coins` (разрешено повторное использование), сумма которого равна `amount`, используя как можно меньше токенов.
Когда мультисет не достигает `amount`, сообщите о `-1`.

**Ограничения:**

- 1 ≤ coins.length ≤ 12
- 1 ≤ coins[i] ≤ 2^31 - 1
- 0 ≤ amount ≤ 10^4
