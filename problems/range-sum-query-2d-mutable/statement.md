Вам предоставляется изменяемый `matrix` плюс сценарий операций для повторения в порядке.
Операция либо `"sumRegion"` со значениями `[row1, col1, row2, col2]`, запрашивая сумму
прямоугольник от `(row1, col1)` до `(row2, col2)` включительно или `"update"` со значениями
`[row, col, value]`, присвоение `matrix[row][col] = value`. Возврат ответов
Операции `"sumRegion"` в порядке. (Это вид функционального стиля классического mutable)
Задача 2D-диапазона обычно решается с помощью 2D двоичного индексированного дерева.

**Ограничения:**
- `1 <= rows, cols <= 200`
- `-1000 <= matrix[i][j], value <= 1000`
- Индексы в каждой операции действительны; появляется по крайней мере один `"sumRegion"`.
