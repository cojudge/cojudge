Дана двоичная матрица размера `m x n`, изначально заполненная нулями. Нужно случайно выбирать ячейку `(i, j)`, для которой `matrix[i][j] == 0`, и менять её значение на `1`. Все нулевые ячейки должны выбираться с одинаковой вероятностью.

Реализуйте класс `FlipMatrix`:

- `FlipMatrix(int m, int n)` создаёт объект для матрицы размера `m x n`.
- `int[] flip()` возвращает координаты случайной нулевой ячейки `[i, j]` и меняет её значение на `1`.
- `void reset()` обнуляет всю матрицу.

Здесь класс называется `FlipMatrix`, поскольку имя `Solution` зарезервировано проверяющей системой. Конструктор и методы соответствуют оригиналу.

Проверка: каждый `flip` должен вернуть допустимые координаты ячейки, ещё не выбранной после создания объекта или последнего `reset`. Принимается любая допустимая последовательность; равномерность статистически не проверяется. Как и в LeetCode, разрешено не более 1000 вызовов, чего недостаточно для полноценной проверки распределения.

**Пример 1:**
```
Вход: operations = ["FlipMatrix","flip","flip","flip","reset","flip"], values = [[3,1],[],[],[],[],[]]
Выход: [null,[1,0],[2,0],[0,0],null,[2,0]]
```
Пояснение: Одна допустимая последовательность: выбираются [1,0], [2,0], затем последняя свободная ячейка [0,0]. После reset можно снова выбрать любую ячейку, здесь [2,0].

**Пример 2:**
```
Вход: operations = ["FlipMatrix","flip","flip","flip","flip"], values = [[2,2],[],[],[],[]]
Выход: [null,[0,0],[0,1],[1,0],[1,1]]
```
Пояснение: При заполнении матрицы 2x2 каждая из четырёх ячеек должна встретиться ровно один раз, в любом порядке.

**Пример 3:**
```
Вход: operations = ["FlipMatrix","flip","reset","flip"], values = [[1,1],[],[],[]]
Выход: [null,[0,0],null,[0,0]]
```
Пояснение: reset сбрасывает состояние, поэтому единственную ячейку можно выбрать повторно.

**Ограничения:**
- `1 <= m, n <= 10^4`
- При каждом вызове `flip` есть хотя бы одна свободная ячейка.
- Не более `1000` вызовов `flip` и `reset`.
