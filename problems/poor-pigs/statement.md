Есть ведра с жидкостью `buckets`, и точно одна из них отравлена. Поросенок, который пьет яд, умирает через `minutesToDie` минуты; в противном случае он выживает. У вас есть `minutesToTest` минуты в общей сложности, и в этом окне свинья может пить в несколько раундов: после каждого раунда вы ждете достаточно долго, чтобы увидеть, какие свиньи умирают до следующего раунда.

При наличии полных раундов `r` одна свинья может различать различные результаты `r + 1` (умирание в раунде 1, 2, ..., `r` или выживание всего). С свиньями `p` количество различимых результатов умножается на `(r + 1)^p`.

Верните наименьшее количество свиней, необходимое для своевременного обнаружения отравленного ведра.

**Ограничения:**
- `1 <= buckets <= 1000`
- `1 <= minutesToDie, minutesToTest <= 100`
