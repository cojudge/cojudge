Вам дается массив `nums` целых чисел `n` и целевое значение `target`. Выберите три записи в попарно разных позициях, чтобы их общая сумма была как можно ближе к `target`, а затем верните эту сумму.

Каждый тестовый случай построен так, что существует точно одна такая ближайшая сумма.

**Ограничения:**
- `3 <= nums.length <= 500`
- `-1000 <= nums[i] <= 1000`
- `-10^4 <= target <= 10^4`
