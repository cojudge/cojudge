Two binary numerals arrive as strings `a` and `b`. Add them together arithmetically and emit the total, again written as a binary string.

**Examples:**

```
Input: a = "11", b = "1"
Output: "100"
```
Here 3 + 1 equals 4, which reads `100` in base two.

```
Input: a = "1010", b = "1011"
Output: "10101"
```
Here 10 + 11 equals 21, which reads `10101` in base two.

**Constraints:**

- `1 <= a.length, b.length <= 10^4`
- `a` and `b` consist only of `'0'` or `'1'` characters.
- Each string does not contain leading zeros except for the zero itself.
