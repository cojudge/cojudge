Дан массив положительных целых чисел `w` с индексацией от нуля. Значение `w[i]` задаёт вес индекса `i`.

Реализуйте класс `WeightedPicker`:

- `WeightedPicker(int[] w)` создаёт объект с массивом весов `w`.
- `int pickIndex()` случайно выбирает индекс от `0` до `w.length - 1` включительно. Вероятность выбора индекса `i` должна быть равна `w[i] / sum(w)`.

Здесь класс называется `WeightedPicker`, поскольку имя `Solution` зарезервировано проверяющей системой. Конструктор и методы соответствуют оригиналу.

Проверка: каждый `pickIndex` должен возвращать индекс из диапазона `[0, w.length)`. Для последовательностей не короче 500 выборов каждый индекс с положительным весом дополнительно должен встретиться хотя бы один раз. Принимается любая последовательность, удовлетворяющая этим условиям; точное распределение статистически не проверяется. Результаты передаются строками с целыми числами.

**Пример 1:**
```
Вход: operations = ["WeightedPicker","pickIndex","pickIndex","pickIndex","pickIndex"], values = [[1,3],[],[],[],[]]
Выход: [null,1,0,1,1]
```
Пояснение: Вес индекса 0 равен 1, а индекса 1 — 3. При каждом вызове проверка принимает любой индекс из допустимого диапазона.

**Пример 2:**
```
Вход: operations = ["WeightedPicker","pickIndex","pickIndex"], values = [[5],[],[]]
Выход: [null,0,0]
```
Пояснение: Индекс всего один, поэтому каждый выбор возвращает 0.

**Пример 3:**
```
Вход: operations = ["WeightedPicker","pickIndex","pickIndex","pickIndex"], values = [[2,5,3],[],[],[]]
Выход: [null,0,1,2]
```
Пояснение: Все индексы имеют положительные веса и должны иметь возможность появиться. При каждом вызове принимается любой допустимый индекс.

**Ограничения:**
- `1 <= w.length <= 10^4`
- `1 <= w[i] <= 10^5`
- Метод `pickIndex` вызывается не более `10^4` раз.
