Представьте себе индексы `0..n-1`, выложенные на сегментах, длина которых равна весу: индекс 0 владеет диапазоном `[0, weights[0])`, индекс 1 владеет `[weights[0], weights[0]+weights[1])` и так далее до общей суммы `S`.

*Примечание по адаптации: * первоначальная задача рисует случайную позицию и возвращает собственный индекс. Поскольку этот судья детерминистский, каждый розыгрыш поставляется абонентом вместо этого: массив `calls` содержит одно целое число на ничью, и значение розыгрыша `c` выбирает позицию `((c mod S) + S) mod S` (так что отрицательные значения обернуты вокруг безопасно).

Внедрить `runWeightedPick(weights, calls)` возвращая один выбранный индекс на значение ничьей, в порядке.

**Ограничения:**
- `1 <= weights.length <= 10^4`
- `1 <= weights[i] <= 10^5`
- `1 <= calls.length <= 10^4`
- `calls[i]` - это любое целое число, подписанное 32.
