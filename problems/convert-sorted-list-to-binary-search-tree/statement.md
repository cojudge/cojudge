Постройте дерево двоичного поиска с балансом высоты из значений восходящего единственно связанного списка.

Пройдите по списку, чтобы собрать его значения в порядке, а затем преобразуйте эту упорядоченную последовательность в сбалансированное дерево: среднее значение становится корнем, а каждая половина рекурсивно становится поддеревом.

Возврат корня дерева. Пустой список порождает пустое дерево, и принимается любое сбалансированное дерево поиска, содержащее точно значения списка.

**Ограничения:**
- `0 <= number of list nodes <= 2 * 10^4`
- `-10^5 <= Node.val <= 10^5`
- Значения появляются в неубывающем порядке.
