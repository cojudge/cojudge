You are given an integer array `nums` and an integer `target`. Build an expression by
placing either `+` or `-` before every element in `nums`, while preserving the element
order.

Return the number of different sign assignments whose expression evaluates to
`target`. The answer is guaranteed to fit in a signed 32-bit integer.

**Constraints:**
- `1 <= nums.length <= 20`
- `0 <= nums[i] <= 1000`
- `0 <= sum(nums) <= 1000`
- `-1000 <= target <= 1000`
