Постройте `n` по сетке `n`, заполненной цифрами `1` через `n * n` по часовой спирали, начиная с верхнего левого угла и первоначально двигаясь вправо.

Пройдите вправо по верхнему краю, вниз по правому краю, влево по нижнему краю и вверх по левому краю, затем продолжайте движение внутрь слой за слоем до тех пор, пока каждая ячейка не удержит значение. Первое число `1`, и каждая последующая ячейка получит следующее целое число.

**Ограничения:**
- `1 <= n <= 20`
