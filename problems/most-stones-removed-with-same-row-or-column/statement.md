Удалите как можно больше камней, когда для каждого удаления требуется партнер строки или столбца.

Камни сидят на целочисленных точках сетки с максимум одним камнем за точку. Камень может быть отнят только в то время, как какой-то другой оставшийся камень делит свой ряд или свою колонку. Планируйте удаления, чтобы очистить максимальное количество.

Учитывая `stones`, где каждая запись `[x, y]`, возвращайте наибольшее количество камней, которые могут исчезнуть.

**Ограничения:**
- `1 <= stones.length <= 1000`
- `0 <= xi, yi <= 10^4`
- Нет двух камней, имеющих общую координату.
