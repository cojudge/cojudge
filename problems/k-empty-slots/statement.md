Есть слоты `n` с номером `1..n`, все начинаются без света. Array `bulbs` - это перестановка: `bulbs[d-1]` - это слот, который загорается в день `d`.

Момент хорош, когда между ними существуют два освещенных слота с точно неосвещенными слотами `k` (так что их позиции различаются по `k+1`).Возвратите самый ранний день, в который существует хороший момент, или `-1`, когда это никогда не происходит.

**Ограничения:**
- `1 <= bulbs.length <= 20000`
- `bulbs` является перестановкой `1..n`.
- `0 <= k < bulbs.length`
