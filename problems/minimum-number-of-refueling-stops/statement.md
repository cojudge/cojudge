Вы начинаете с `startFuel` единиц топлива и должны отправиться в пункт назначения `target` единиц вдоль прямой дороги. Ваш автомобиль потребляет одну единицу топлива на единицу расстояния.

По пути есть заправочные станции, описанные `stations`, где `stations[i] = [position, fuel]` означает, что на расстоянии `position` от начала вы можете остановиться один раз, чтобы получить единицы `fuel`.

Возвращайте наименьшее количество остановок, необходимых для достижения пункта назначения. Если поездка невозможна, возвращайте `-1`. Запуск топлива считается нулевой остановкой.

**Ограничения:**
- `1 <= target, startFuel <= 10^9`
- `0 <= stations.length <= 500`
- `0 <= position <= target`
- `1 <= fuel <= 10^5`
- Позиции строго увеличиваются.
