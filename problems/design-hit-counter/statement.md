Создайте счётчик, который регистрирует обращения с временными метками в секундах и сообщает число обращений за последние 5 минут (300 секунд). Обращение в момент `t` учитывается при запросе в момент `T` тогда и только тогда, когда `T - 300 < t <= T`.

Реализуйте класс `HitCounter`:

- `HitCounter()` создаёт объект.
- `void hit(int timestamp)` регистрирует обращение в момент `timestamp`.
- `int getHits(int timestamp)` возвращает число обращений за последние 5 минут, заканчивающиеся в момент `timestamp`.

Временные метки во всех вызовах идут в неубывающем порядке.

Используйте имя класса `HitCounter`; имя `Solution` зарезервировано проверяющей системой. Конструктор и методы соответствуют оригиналу.

Проверка детерминированная: результат каждого `getHits` точно сравнивается с эталонной моделью на основе очереди.

**Пример 1:**
```
Вход: operations = ["HitCounter","hit","hit","hit","getHits"], values = [[],[1],[2],[3],[4]]
Выход: [null,null,null,null,3]
```
Пояснение: Обращения в моменты 1, 2 и 3 находятся в окне (4-300, 4], поэтому getHits(4) возвращает 3.

**Пример 2:**
```
Вход: operations = ["HitCounter","hit","hit","getHits","getHits"], values = [[],[1],[2],[301],[302]]
Выход: [null,null,null,1,0]
```
Пояснение: В момент 301 учитывается окно (1, 301]: обращение в момент 1 уже устарело, а обращение в момент 2 ещё учитывается. В момент 302 оба обращения находятся вне окна (2, 302].

**Пример 3:**
```
Вход: operations = ["HitCounter","getHits"], values = [[],[100]]
Выход: [null,0]
```
Пояснение: Обращений не было, поэтому запрос возвращает 0.

**Ограничения:**
- `1 <= timestamp <= 2 * 10^9`
- Временные метки `timestamp` во всех вызовах идут в неубывающем порядке.
- Не более `300` вызовов `hit` и `getHits`.
