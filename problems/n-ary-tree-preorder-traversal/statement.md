Каждый узел в дереве N-ary может иметь любое количество упорядоченных потомков. Дерево прибывает в виде одной строки `data`, держащей скобчатый список токенов в порядке уровня, где `null` заканчивает детскую группу каждого узла. Например, `"[1,null,3,2,4,null,5,6]"` означает корень 1 с детьми 3, 2, 4 и узел 3 с детьми 5, 6. Пустое дерево `"[]"`.

Верните заказ на посещение: каждый узел перед своими детьми, с детьми, обработанными слева направо.

**Ограничения:**
- Количество токенов составляет максимум `10^4`.
- Значения вписываются в 32-бит подписанных целых чисел.

Адаптация: источник принимает объект N-ary `Node`, который этот судья не может выразить.Поэтому вход представляет собой строку порядка уровня, описанную выше, а выход - `int_list`; разбор происходит внутри ссылки.
