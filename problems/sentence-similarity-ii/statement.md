Два предложения — это списки слов. Они похожи, когда содержат одинаковое количество слов и каждая пара слов в соответствующих положениях может быть связана, где связь теперь цепляется через заданные пары:

- Каждое слово связано с самим собой.
- Каждая из перечисленных пар связывает два слова в обоих направлениях.
- Связь транзитивна: когда `a` ссылается на `b`, а `b` ссылается на `c`, `a` ссылается на `c`.

Учитывая `sentence1`, `sentence2` и `similarPairs` (каждая запись содержит два слова), решите, являются ли предложения похожими в соответствии с этим правилом цепей. Обратите внимание, что два слова, разделяющие группу, совпадают, даже если ни одна прямая пара не называет их вместе.

**Ограничения:**
- `1 <= sentence1.length, sentence2.length <= 1000`
- `0 <= similarPairs.length <= 2000`
- Слова содержат строчные буквы.
