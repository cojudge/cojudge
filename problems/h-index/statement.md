Учитывая количество цитирований для каждой статьи, вычислите h-индекс исследователя.

h-индекс является крупнейшим `h`, так что, по крайней мере, `h` бумаги имеют `h` или ZXQXZ.
Реализуйте `hIndex(citations)`, возвращая максимум.

**Ограничения:**
- `1 <= citations.length <= 5000`
- `0 <= citations[i] <= 1000`
