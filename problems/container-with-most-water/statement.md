Вам дается целочисленная матрица `height`, где значение по индексу `i` обозначает высоту вертикальной стенки, стоящей в этом положении. Выберите два положения, которые будут служить сторонами судна (основа - ось x) и определите наибольшее количество воды, которое может сохранить такое судно. Верните этот максимум.

Сохраняемое количество для пары положений — это промежуток между ними, умноженный на более короткую из двух стен.

**Ограничения:**
- `n == height.length`
- `2 <= n <= 10^5`
- `0 <= height[i] <= 10^4`
