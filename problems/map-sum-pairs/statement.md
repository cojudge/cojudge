Ведите струнный магазин с префиксными суммами. Адаптация дизайна: вместо класса реализуйте `runMapSum(operations, keys, vals)`.

Конвенция по индексу `i`:

- `operations[i]` - это `"insert"` или `"sum"`.
- Для `"insert"` вставьте `keys[i]` со значением `vals[i]`, перезаписав любое предыдущее значение для этого ключа.
- Для `"sum"`, `keys[i]` является префиксом (vals[i] игнорируется).Прибавьте общее количество всех сохраненных значений, ключ которых начинается с этого префикса.

Верните список сумм для звонков по порядку.

**Ограничения:**
- Количество операций в тесте находится между 1 и 20.
- Ключи используют строчные буквы; значения вставки лежат в [1, 1000].
