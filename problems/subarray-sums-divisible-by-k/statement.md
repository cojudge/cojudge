Учитывая целочисленный массив `nums` и положительное целое число `k`, подсчитайте смежные подкатегории, общее количество элементов которых является кратным `k`.

Подкатегория - это любой непустый последовательный срез `nums[i..j]`. Его общая сумма должна удовлетворять `sum % k == 0`.

**Ограничения:**
- `1 <= nums.length <= 30000`
- `-10000 <= nums[i] <= 10000`
- `2 <= k <= 10000`
