Каждый узел двоичного дерева содержит целое число `0` до `25`, кодируя буквы `a` до `z` (`0` - `a`, `25` - `z`).

Для каждого листа (узел без потомков) напишите буквы по пути от этого листа до корня, лист первый. Среди всех таких лист-корневых струн верните лексикографически самую маленькую.

**Ограничения:**
- `1 <= number of nodes <= 8500`
- `0 <= node value <= 25`
