По целочисленному массиву `nums` реализуйте случайное перемешивание. Все перестановки должны быть равновероятны.

Реализуйте класс `Shuffler`:

- `Shuffler(int[] nums)` создаёт объект с массивом `nums`.
- `int[] reset()` восстанавливает исходный порядок и возвращает массив.
- `int[] shuffle()` возвращает случайную перестановку массива.

Здесь класс называется `Shuffler`, поскольку имя `Solution` зарезервировано проверяющей системой. Конструктор и методы соответствуют оригиналу.

Проверка: каждый результат `shuffle` должен быть перестановкой исходного массива с теми же элементами и числом вхождений, а `reset` должен точно восстанавливать исходный порядок. Принимается любая допустимая последовательность; равномерность распределения перестановок статистически не проверяется.

**Пример 1:**
```
Вход: operations = ["Shuffler","shuffle","reset","shuffle"], values = [[1,2,3],[],[],[]]
Выход: [null,[3,1,2],[1,2,3],[2,3,1]]
```
Пояснение: Одна допустимая последовательность: перемешиваем в [3,1,2], reset восстанавливает [1,2,3], затем перемешиваем в [2,3,1]. Для shuffle принимается любая перестановка.

**Пример 2:**
```
Вход: operations = ["Shuffler","shuffle"], values = [[5],[]]
Выход: [null,[5]]
```
Пояснение: У массива из одного элемента только одна перестановка.

**Пример 3:**
```
Вход: operations = ["Shuffler","shuffle","shuffle","reset"], values = [[1,2,3,4],[],[],[]]
Выход: [null,[3,1,4,2],[4,2,1,3],[1,2,3,4]]
```
Пояснение: Каждый shuffle должен сохранять элементы и число их вхождений. reset должен точно восстановить исходный порядок.

**Ограничения:**
- `1 <= nums.length <= 50`
- `-10^6 <= nums[i] <= 10^6`
- Все значения в `nums` уникальны.
