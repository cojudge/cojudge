Вы получаете целочисленный массив `nums` и две границы `left` и `right` с `left <= right`. Прилегающий сегмент массива называется подходящим, когда наибольшее значение внутри него лежит между `left` и `right` включительно.

Подсчитайте, сколько непустых смежных подложек подходит.

**Ограничения:**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`
- `0 <= left <= right <= 10^9`
