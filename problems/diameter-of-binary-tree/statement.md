Вам вручают `root` двоичного дерева. Вычислите, насколько широко растягивается дерево, сообщив его диаметр.

Здесь диаметр означает наибольшее количество краев, найденных на любом маршруте, соединяющем два узла дерева. Этот маршрут не должен включать корень; важно только количество краев от одной конечной точки до другой.

**Ограничения:**

- Количество узлов в дереве находится между `1` и `10000` включительно.
- Every node's stored value satisfies `-100 <= node.val <= 100`.
