Вы получаете однопоточные функции `n` с пометкой `0` через `n - 1`, а также список журналов, описывающий, когда каждая функция начинается и заканчивается. Каждая запись выглядит как `"id:start|end:timestamp"` с целочисленной меткой времени, например `"0:start:0"`. Ровно одна функция выполняется в любой момент; запущенная функция приостанавливается, пока выполняется вложенная функция.

Для каждой функции сложите только срезы времени, в течение которых сама функция находится поверх стека вызовов. Марка `end` охватывает весь блок времени, поэтому вызов от `2` до `5` занимает 4 единицы (`5 - 2 + 1`).

Внедряйте `exclusiveTime(n, logs)`, возвращая массив, где позиция `i` содержит эксклюзивную общую для функции `i`. Логи прибывают в порядке метки времени и всегда образуют действительное гнездование.

**Ограничения:**
- `1 <= n <= 100`
- `1 <= logs.length <= 500`
- Каждый журнал - `"id:start|end:timestamp"`, `0 <= id < n`, `0 <= timestamp <= 10^9`.
- Журналы сортируются по временным меткам и описывают правильно вложенные, не пересекающиеся вызовы.
