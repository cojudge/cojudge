Односвязанный список `head` содержит уникальные значения. Один из его узлов содержит значение `val`, и этот узел гарантированно не будет последним.

Удалите из списка узел, удерживающий `val`, сохранив при этом относительный порядок всех остальных узлов, затем верните заголовок обновленного списка.

*Примечание по адаптации: * оригинальное заявление передает вам только узел для удаления и запрашивает обновление `void`. Здесь функция получает заголовок списка плюс целевое значение `val` и возвращает заголовок списка после удаления, что позволяет судье проверить результат напрямую. Метод ссылки тот же: скопировать значение следующего узла над целью и пропустить следующий узел.

**Ограничения:**
- Количество узлов находится в диапазоне `[2, 1000]`.
- `-1000 <= Node.val <= 1000`
- Каждая ценность в списке уникальна.
- Значение `val` существует в списке и не является значением хвоста.
