Реализуйте хеш-таблицу без использования готовых библиотечных хеш-таблиц.

Реализуйте класс `MyHashMap`:

- `MyHashMap()` создаёт пустой объект.
- `void put(int key, int value)` добавляет пару ключ-значение или обновляет значение существующего ключа.
- `int get(int key)` возвращает значение по ключу или `-1`, если ключ отсутствует.
- `void remove(int key)` удаляет ключ и его значение. Если ключ отсутствует, ничего не делает.

Сохраните имя класса `MyHashMap`: имя `Solution` зарезервировано проверяющей системой для запускающего кода. Конструктор и методы соответствуют оригинальной задаче. В последовательности результатов конструктору, `put` и `remove` соответствует `null`, а `get` — возвращённое целое число.

**Пример 1:**
```
Вход: operations = ["MyHashMap","put","put","get","get","put","get","remove","get"], values = [[],[1,1],[2,2],[1],[3],[2,1],[2],[2],[2]]
Выход: [null,null,null,1,-1,null,1,null,-1]
```
Пояснение: После put(1,1) и put(2,2) вызов get(1) возвращает 1, а get(3) — -1. Вызов put(2,1) обновляет значение ключа 2 до 1. После remove(2) вызов get(2) возвращает -1.

**Пример 2:**
```
Вход: operations = ["MyHashMap","get","put","get","remove","get"], values = [[],[5],[5,7],[5],[5],[5]]
Выход: [null,-1,null,7,null,-1]
```
Пояснение: Изначально get(5) возвращает -1. После put(5,7) он возвращает 7, а после remove(5) — снова -1.

**Пример 3:**
```
Вход: operations = ["MyHashMap","put","remove"], values = [[],[3,9],[3]]
Выход: [null,null,null]
```
Пояснение: Вызовов get нет, поэтому все элементы результата равны null.

**Ограничения:**
- `0 <= key, value <= 10^6`
- Суммарно не более `10^4` вызовов `put`, `get` и `remove`.
- Каждая последовательность начинается с `MyHashMap`.
