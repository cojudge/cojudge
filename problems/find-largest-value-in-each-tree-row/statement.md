Прогуляйтесь по двоичному древу ряд за рядом сверху вниз и зафиксируйте для каждого уровня глубины наибольшее значение, появляющееся на этом уровне. Верните эти максимумы из самого мелкого ряда в самый глубокий.

**Ограничения:**
- Количество узлов находится в диапазоне `[0, 10^4]`
- `-2^31 <= Node.val <= 2^31 - 1`
