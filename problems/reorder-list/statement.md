Вы получаете головку отдельно связанной цепи, нумеруя ее узлы спереди как:

L0 → L1 → ... → Ln — 1 → Ln

Вплетайте цепь в эту чередующуюся схему:

L0 → Ln → L1 → Ln — 1 → L2 → Ln — 2 →

Значения, удерживаемые узлами, должны оставаться на месте; могут быть перемонтированы только связи между узлами.

Возвращайте голову тканой цепи.

**Ограничения:**
- Количество узлов в списке находится в диапазоне `[0, 5 * 10^4]`.
- `1 <= Node.val <= 1000`
