Учитывая корень двоичного дерева, перечислите каждый путь от корня до листа. Лист - это узел без потомков. Каждый путь записывается как значения узлов, к которым присоединяется `"->"`, например `"1->2->5"`.

Возвращайте все эти пути в любом порядке.

**Ограничения:**
- `1 <= number of nodes <= 100`
- `-100 <= Node.val <= 100`
