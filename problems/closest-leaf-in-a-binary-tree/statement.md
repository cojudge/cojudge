Вам дается корень двоичного дерева, в котором каждый узел содержит отдельное целое число, плюс целевое значение `k`, которое появляется где-то в дереве.

Лист — это узел без потомков. Вы можете путешествовать по родительско-детским связям в любом направлении, а длина маршрута — это количество используемых краев.

Возврат значения, хранящегося в листе, который максимально приближен к узлу, удерживающему `k`.Когда несколько листьев завязывают на кратчайшее расстояние, принимается любой из них.

**Ограничения:**
- `1 <= number of nodes <= 1000`
- `1 <= Node.val <= 1000`
- Каждая ценность дерева уникальна.
- Некоторые узлы имеют значение `k`.
