Последовательность цифр является аддитивной, когда она может быть разделена по крайней мере на три числа, где каждый
Число от третьего равно сумме двух предыдущих (например, 1, 1, 2, 3, 5).
может не нести ведущие нули, если само число не является точно `"0"`.
Цифровая строка `num` является аддитивной.

**Ограничения:**
- `1 <= num.length <= 35`
- `num` содержит только цифры.
