Вам дается целочисленный массив `nums`, расположенный в неубывающем порядке. Выдавите повторы непосредственно внутри массива так, чтобы каждое отдельное значение выжило ровно один раз, оставив выживших в их первоначальном относительном порядке.

Вызовите количество различных значений `k`. Отдайте `k`. Первые слоты `k` `nums` должны содержать эти различные значения от наименьшего до самого большого.

**Ограничения:**

- 1 ≤ nums.length ≤ 3 * 10^4
- -100 ≤ nums[i] ≤ 100
- Числа отсортированы в неубывающем порядке.
