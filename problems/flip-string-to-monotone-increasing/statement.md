Вы получаете двоичную строку `s`, содержащую только `'0'` и `'1'`. В одном движении вы можете перевернуть любой один символ (`'0'` на `'1'` или `'1'` на `'0'`).

Струна монотонно увеличивается, когда она состоит из некоторого количества `'0'`, за которым следует некоторое количество `'1'` (обе части могут быть пустыми).Верните наименьшее количество сальто, необходимое для увеличения монотона `s`.

**Ограничения:**
- `1 <= s.length <= 100000`
- `s` содержит только `'0'` и `'1'`.
