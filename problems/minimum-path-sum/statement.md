Вам дается таблица `m x n` `grid`, записи которой все нулевые или положительные. Начиная с верхнего левого угла, вы должны достичь нижнего правого угла, шагая только по одной ячейке вниз или по одной ячейке вправо за раз. Среди всех таких монотонных маршрутов найдите тот, чьи посещенные ячейки складываются в наименьшую сумму, и верните эту сумму.

**Ограничения:**
- m == grid.length
- n == grid[i].length
- 1 ≤ m, n ≤ 200
- 0 ≤ grid[i][j] ≤ 200
