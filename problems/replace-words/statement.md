Вы получаете список `dictionary` корневых слов и предложение разрозненных слов. Для каждого слова в предложении ищите самый короткий корень, который является его префиксом; когда он существует, поменяйте все слово на этот корень. Слова без соответствующего корня остаются неизменными.

Внедрите `replaceWords(dictionary, sentence)`, возвращая восстановленное предложение с одними пробелами.

**Ограничения:**
- `1 <= dictionary.length <= 1000`
- `1 <= dictionary[i].length <= 100`
- `1 <= sentence.length <= 10^6`; слова содержат строчные буквы, соединенные одними пробелами.
