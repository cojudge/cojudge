Вы начинаете с одного `A` на экране и четырех операций: наберите еще один `A`, скопируйте все показанное, вставьте буфер обмена или выберите все (выберите, должно быть, предшествуете полезной копии). С помощью именно клавишных нажатий `n`, сколько символов `A` может быть на экране максимум?

Внедряйте `maxA(n)`, возвращая этот максимум.

**Ограничения:**
- `1 <= n <= 50`
