Вы получаете массив `nums` длины `n`, содержащий отдельные целые числа, взятые из `0` через `n` включительно. Ровно одно значение в этом полном диапазоне не отображается в массиве. Идентифицируйте и верните отсутствующее значение.

**Ограничения:**

- n == nums.length
- 1 ≤ n ≤ 10^4
- 0 ≤ nums[i] ≤ n
- Все числа чисел уникальны.
