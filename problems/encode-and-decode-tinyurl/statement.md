Создайте службу сокращения URL-адресов, реализовав класс `Codec` двумя способами:

- `encode(longUrl)` превращает длинный URL в короткий URL, который начинается с `http://tinyurl.com/`, за которым следует непустый код. Кодирование должно быть идемпотентным: кодирование уже видимого URL возвращает существующую короткую ссылку. Отдельные URL должны отображаться в отдельные короткие ссылки, а короткая ссылка никогда не должна равняться длинному URL.
- `decode(shortUrl)` удаляет префикс, просматривает код и возвращает исходный длинный URL.

Судья создает один `Codec` в тестовом случае, кодирует каждый URL-адрес дважды, декодирует первую короткую ссылку и проверяет, что оба кода согласны, декодированное значение равно вводу, а контракт короткой ссылки выше удерживает для всех URL-адресов.

**Ограничения:**

- `0 <= urls.length <= 30`
- `1 <= url.length <= 500`
- `url` содержит печатные символы ASCII без пробелов или запятых (буквы, цифры и символы, такие как `:/?&=+.-_~@%#`).
