Вам дают `widths`, массив 26 положительной ширины для букв `a` через `z` и строку `s` строчных букв. Написание прокладывает символы слева направо на строках, каждая из которых держит максимум 100 единиц. Персонаж помещается на текущую линию, когда она подходит; в противном случае начинается новая линия и персонаж идет туда.

Возврат двухэлементного массива `[totalLines, lastLineWidth]`: количество используемых линий и занимаемая ширина конечной линии.

**Ограничения:**
- `widths.length == 26`
- `2 <= widths[i] <= 10`
- `1 <= s.length <= 1000`
- `s` содержит только английские буквы
