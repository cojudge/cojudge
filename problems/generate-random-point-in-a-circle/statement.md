Круг описывается его радиусом и его центральной точкой. Напишите рутину, которая производит одну точку, лежащую где-то внутри (или точно на) этого круга.

**Портативная адаптация: ** Эта задача является функциональной версией задачи проектирования класса. Радиус и обе координаты центра прибывают в виде десятичных строк, поэтому каждый язык получает идентичные входные данные, а точка возвращается в виде двухэлементного списка десятичных строк `[x, y]`. Плавающие ответы сравниваются с допуском, а не с точным соответствием текста.

** Поведение:**

- Размеры `radius`, `xCenter`, `yCenter` как значения двойной точности.
- Возвращают две десятичные струны, которые разбираются как конечные двойники.
- Обратная точка должна удовлетворять требованиям `distance((x, y), center) <= radius + 1e-9`.
- Любая валидная точка считается правильной; распределение не оценивается. Ссылка использует фиксированное семя для воспроизводимости, но пользовательский код может использовать любой источник случайности (возврат самого центра также действителен, хотя и не однороден).

**Ограничения:**

- `0 < radius <= 10^8`
- `-10^7 <= xCenter, yCenter <= 10^7`
- Вводы — это конечные десятичные строки.
