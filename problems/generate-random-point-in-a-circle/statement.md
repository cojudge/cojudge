По радиусу и координатам центра круга реализуйте генерацию случайной точки с равномерным распределением по площади круга.

Реализуйте класс `RandPoint`:

- `RandPoint(double radius, double xCenter, double yCenter)` создаёт объект с радиусом `radius` и центром `(xCenter, yCenter)`.
- `double[] randPoint()` возвращает случайную точку в виде массива `[x, y]`. Граница круга включается.

Здесь класс называется `RandPoint`, поскольку имя `Solution` зарезервировано проверяющей системой. Конструктор и методы соответствуют оригиналу. В C# метод называется `NextPoint`, так как язык запрещает совпадение имени метода с именем класса.

Проверка: каждый результат должен представлять пару вещественных координат `[x,y]`, для которых `(x - xCenter)^2 + (y - yCenter)^2 <= radius^2 * (1 + 1e-9) + 1e-9`. Принимается любая допустимая последовательность точек; равномерность статистически не проверяется. В этой версии аргументы конструктора передаются целыми числами: радиус и координаты центра целочисленные, что допустимо в оригинальной задаче. Точки передаются компактной строкой `"[x,y]"`.

**Пример 1:**
```
Вход: operations = ["RandPoint","randPoint","randPoint","randPoint"], values = [[1,0,0],[],[],[]]
Выход: [null,[0.1,0.2],[0,0],[-0.5,0.5]]
```
Пояснение: Принимается любая точка на расстоянии не больше 1 от начала координат, в том числе сам центр.

**Пример 2:**
```
Вход: operations = ["RandPoint","randPoint"], values = [[2,3,-1],[]]
Выход: [null,[3,-1]]
```
Пояснение: Центр (3,-1) находится на нулевом расстоянии от себя и проходит проверку, хотя постоянный возврат центра не даёт равномерного распределения.

**Пример 3:**
```
Вход: operations = ["RandPoint","randPoint","randPoint"], values = [[5,2,-3],[],[]]
Выход: [null,[2,-3],[6.5,-1.0]]
```
Пояснение: И центр, и любая точка на расстоянии не больше 5.0 от (2,-3) проходят проверку.

**Ограничения:**
- `0 < radius <= 10^8`
- `-10^7 <= xCenter, yCenter <= 10^7`
- Не более `3 * 10^4` вызовов `randPoint`.
