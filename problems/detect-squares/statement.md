Обработайте поток точечных операций и сообщите, сколько квадратов, расположенных по оси, может быть сформировано для каждого запроса.

Операция `add` хранит одну копию своей точки. Допускаются дублирующие точки и учитываются как различные варианты. Для операции `count` в `[x, y]` подсчитайте все способы выбора трех сохраненных точек, которые вместе с точкой запроса образуют квадрат, выровненный по оси, с положительной длиной стороны.

**Портативная адаптация функций: ** Реализуйте `runDetectSquares(operations, points)`. Решетки выровнены по индексу. Первая операция всегда `"DetectSquares"` с проигнорированной точкой заполнителя `[0,0]`. Каждая более поздняя операция `"add"` или `"count"`, с ее точкой в одном ряду `points`. Возвращайте целочисленный массив, содержащий одно значение для каждой операции `count`, в порядке. Не возвращайте записи для конструктора или операций `add` и не реализуйте отдельный класс задач проектирования.

**Ограничения:**
- `operations.length == points.length`
- `1 <= operations.length <= 3001`
- `points[i]` содержит ровно два целых числа в диапазоне `0..1000`
- `operations[0] == "DetectSquares"` и `points[0] == [0,0]`
- Каждая последующая операция `"add"` или `"count"`
- Каждый результат подсчета вписывается в подписанное целое число 32-бит.
