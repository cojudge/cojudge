Write the binary form of a positive integer without extra leading zeroes, then swap every `0` to `1` and every `1` to `0`. Return the integer value of the swapped form.

**Example 1:**

```
Input: num = 5
Output: 2
Explanation: 5 is 101 in binary; swapping gives 010, which is 2.
```

**Example 2:**

```
Input: num = 1
Output: 0
Explanation: 1 is 1 in binary; swapping gives 0.
```

**Example 3:**

```
Input: num = 7
Output: 0
Explanation: 7 is 111; swapping gives 000, which is 0.
```

**Constraints:**

- `1 <= num < 2^31`
