Ряд клумбы использует `1` для посаженного участка и `0` для пустого. Новые цветы не могут касаться: никакие два посаженных участка не могут сидеть бок о бок. Учитывая `flowerbed` и `n`, решите, можно ли добавлять новые цветы `n`, не нарушая правила.

**Ограничения:**
- `1 <= flowerbed.length <= 20000`, записи 0 или 1.
- `0 <= n <= flowerbed.length`; никаких смежных во входе.
