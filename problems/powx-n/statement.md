Внедрить экспоненциацию для десятичной базы `x` и 32-битного целого показателя `n`.

Возврат `x` повышен до `n`. Ваш алгоритм должен работать во времени `O(log |n|)`, а не умножать время `|n|`.

**Портативная адаптация струн: ** База подается в виде действительной конечной десятичной строки, поэтому каждый поддерживаемый язык получает один и тот же вход. Пропорция `x` как двуточное значение с плавающей точкой и возвращает результат в виде десятичной строки, которую можно разобрать как двойную. Допускается научная нотация. Ответы проверяются с абсолютной и относительной толерантностью. `NaN`, бесконечность и неформированные выходные строки отвергаются.

**Ограничения:**
- `-100 < x < 100`
- `-2^31 <= n <= 2^31 - 1`
- `x != 0` или `n > 0`
- `-10^4 <= x^n <= 10^4`
