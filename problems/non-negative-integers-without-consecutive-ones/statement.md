Count how many integers `x` with `0 <= x <= n` have no two adjacent `1` bits in binary. For example 5 is `101` and qualifies, while 3 is `11` and does not.

**Example 1:**
```
Input: n = 5
Output: 5
Explanation: Values 0,1,2,4,5 qualify; 3 is 11 in binary.
```

**Example 2:**
```
Input: n = 1
Output: 2
```

**Example 3:**
```
Input: n = 2
Output: 3
```

**Constraints:**
- `0 <= n <= 10^9`.
