Вы начинаете с полного двоичного дерева (каждый уровень заполнен, за исключением, возможно, последнего, заполненного слева направо), указанного как `root`.

Вместо того, чтобы создавать обычный класс вставки, реализуйте `runCbtInserter(root, operations, values)`, который воспроизводит след: каждая запись `operations` является `"insert"` или `"getRoot"`, с выровненной записью `values`, удерживающей значение для `"insert"` (игнорируется для `"getRoot"`). Для `"insert"` добавьте новый узел, чтобы дерево оставалось полным и сообщало значение родителя; для `"getRoot"` сообщайте значение текущего корня. Возвращайте все сообщенные значения в порядке.

**Ограничения:**
- Количество узлов начинается с `>= 1` и остается `<= 10^4`.
- Значения узлов вписываются в целое число, подписанное 32-битом
- `1 <= operations.length <= 10^4` — это `"insert"` или `"getRoot"`.
