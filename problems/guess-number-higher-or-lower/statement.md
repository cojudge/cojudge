Вы играете в игру Guess с скрытым номером `pick` в диапазоне от `1` до `n`.
Взаимодействуйте с объектом судьи `game` — ваш код никогда не получает `pick` напрямую:

- `guess(num)` возвращает `-1`, если `num > pick` (ваше предположение выше выбранного числа),
- `1`, если `num < pick` (ваше предположение ниже выбранного числа),
- `0` if `num == pick` (you found it).

Внедряйте `guessNumber(n, game)`, чтобы он возвращал `pick`. Бинарный поиск находит его в догадках `O(log n)`; судья подсчитывает ваши звонки `guess` и сообщает неправильный ответ, если вы превышаете **100** вызовы по тестовому делу.

Имена методов на языке: Java `game.guess(num)`, Python `game.guess(num)`, C++ `game.guess(num)`, C# `game.Guess(num)`, Rust `game.guess(num)`, Go `game.Guess(num)`, TypeScript `game.guess(num)`, PHP `$game->guess($num)`.

**Ограничения:**

- `1 <= n <= 2^31 - 1`
- `1 <= pick <= n`
- В большинстве случаев 100 `guess` вызывается в тестовом случае.
