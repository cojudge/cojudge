Вы получаете целочисленный список `nums`, который начал сортироваться вверх без повторов, а затем, возможно, был повернут на каком-то повороте, плюс целое число `target`.

Найдите `target` внутри `nums` и верните его положение.Когда `target` никогда не появится, верните -1 вместо этого.

**Ограничения:**

- 1 ≤ nums.length ≤ 5000
- -10^4 ≤ nums[i] ≤ 10^4
- Все значения цифр уникальны.
- Номера — это восходящий массив, который, возможно, вращается.
- -10^4 ≤ target ≤ 10^4
