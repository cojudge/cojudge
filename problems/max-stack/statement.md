Создайте стек, который помимо обычных операций добавления, удаления и чтения вершины умеет возвращать и удалять максимальный элемент.

Реализуйте класс `MaxStack`:

- `MaxStack()` создаёт пустой стек.
- `void push(int x)` добавляет `x` на вершину.
- `int pop()` удаляет и возвращает элемент вершины.
- `int top()` возвращает элемент вершины без удаления.
- `int peekMax()` возвращает максимальный элемент без удаления.
- `int popMax()` удаляет и возвращает максимальный элемент. Если максимум встречается несколько раз, удаляется вхождение, ближайшее к вершине.

Используйте имя класса `MaxStack`; имя `Solution` зарезервировано проверяющей системой. Конструктор и методы соответствуют оригиналу.

**Пример 1:**
```
Вход: operations = ["MaxStack","push","push","push","top","popMax","top","peekMax","pop","top"], values = [[],[5],[1],[5],[],[],[],[],[],[]]
Выход: [null,null,null,null,5,5,1,5,1,5]
```
Пояснение: Добавляем 5, 1, 5. Вершина равна 5. popMax удаляет верхнюю 5, после чего вершина равна 1, а максимум — 5. pop удаляет 1, оставляя на вершине 5.

**Пример 2:**
```
Вход: operations = ["MaxStack","push","push","popMax","top"], values = [[],[1],[2],[],[]]
Выход: [null,null,null,2,1]
```
Пояснение: Добавляем 1 и 2. popMax удаляет 2, после чего на вершине остаётся 1.

**Пример 3:**
```
Вход: operations = ["MaxStack","push","push","peekMax","pop","peekMax"], values = [[],[2],[7],[],[],[]]
Выход: [null,null,null,7,7,2]
```
Пояснение: Добавляем 2 и 7. Максимум равен 7. pop удаляет 7, и максимум становится равным 2.

**Ограничения:**
- Значения помещаются в 32-битное знаковое целое число.
- Суммарно не более `10^4` вызовов `push`, `pop`, `top`, `peekMax` и `popMax`.
- При вызове `pop`, `top`, `peekMax` или `popMax` стек не пуст. Каждая последовательность начинается с `MaxStack`.
