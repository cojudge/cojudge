Создайте структуру данных, которая поддерживает добавление чисел и проверку наличия пары ранее добавленных чисел с заданной суммой.

Реализуйте класс `TwoSum`:

- `TwoSum()` создаёт пустой объект.
- `void add(int number)` добавляет число `number`.
- `boolean find(int value)` возвращает `true`, если сумма двух сохранённых элементов, полученных разными добавлениями, равна `value`, иначе `false`. Одно вхождение нельзя использовать дважды: для `value = 2 * x` нужны два вхождения `x`.

Используйте имя класса `TwoSum`; имя `Solution` зарезервировано проверяющей системой. Конструктор и методы соответствуют оригиналу.

**Пример 1:**
```
Вход: operations = ["TwoSum","add","add","add","find","find"], values = [[],[1],[3],[5],[4],[7]]
Выход: [null,null,null,null,true,false]
```
Пояснение: После добавления 1, 3 и 5 сумма 4 получается как 1 + 3, поэтому ответ true. Пары с суммой 7 нет, ответ false.

**Пример 2:**
```
Вход: operations = ["TwoSum","add","add","find"], values = [[],[0],[0],[0]]
Выход: [null,null,null,true]
```
Пояснение: Два сохранённых нуля дают сумму 0.

**Пример 3:**
```
Вход: operations = ["TwoSum","add","find","find"], values = [[],[5],[5],[10]]
Выход: [null,null,false,false]
```
Пояснение: Единственное число 5 нельзя использовать дважды, поэтому ни для 5, ни для 10 подходящей пары пока нет.

**Ограничения:**
- `-10^5 <= number, value <= 10^5`
- Не более `10^4` вызовов `add` и `find`.
- Каждая последовательность начинается с `TwoSum`. Методы `add` и `find` принимают по одному аргументу.
