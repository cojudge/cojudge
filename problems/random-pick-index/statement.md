Массив `nums` может содержать повторяющиеся значения. Учитывая `target`, который гарантированно происходит в `nums`, возвращайте любой индекс `i` с `nums[i] == target`.

*Интерфейс примечание: * оригинальная формулировка - это класс, который хранит `nums` в своем конструкторе и отвечает на многие запросы `pick(target)` с равномерно случайным действительным индексом. Поскольку судья не может проверить случайность напрямую, это РЕПО адаптирует задачу к одной чистой функции `pick(nums, target)`. Любой действительный индекс принимается: проверка только проверяет `0 <= answer < nums.length` и `nums[answer] == target`, а не распределение. Решение, которое всегда возвращает первое совпадение, поэтому проходит здесь, в то время как подлинная версия LeetCode также потребует, чтобы каждый действительный индекс был одинаково вероятным.

**Ограничения:**
- `1 <= nums.length <= 2 * 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `target` встречается по меньшей мере один раз в `nums`.
