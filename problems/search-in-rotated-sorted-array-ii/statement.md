Начните с целочисленного списка `nums`, расположенного в неубывающем порядке; допускаются повторы.

Перед вашим звонком список переворачивается в какую-то скрытую точку выреза `k` (`0 <= k < nums.length`), уступая `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]` (0-индексированный). В качестве иллюстрации `[0,1,2,4,4,4,5,6,6,7]` вырезанный на позиции `5` превращается в `[4,5,6,6,7,0,1,2,4,4]`.

Принимая повернутый список `nums` плюс целое число `target`, укажите, отображается ли `target`: отвечайте `true`, когда он это делает, и `false` в противном случае.

Постарайтесь сократить общее количество операций, насколько это возможно.

**Ограничения:**
- `1 <= nums.length <= 5000`
- `-10^4 <= nums[i] <= 10^4`
- `nums` гарантированно будет вращаться в некотором повороте.
- `-10^4 <= target <= 10^4`
