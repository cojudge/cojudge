Вам предоставляется словарь `words`, где каждая запись является строчным словом. За один запрос вы также получаете префиксную строку `pref` и суффиксную строку `suff`.

Найдите самый большой индекс `i`, такой, что `words[i]` начинается с `pref` и заканчивается `suff`. Если ни одно словарное слово не удовлетворяет обоим концам, верните `-1`.

Адаптация для этого судьи: исходная задача определяет класс `WordFilter`, чей конструктор хранит словарь и чей метод `f(pref, suff)` отвечает на каждый запрос.Здесь вся работа конденсируется в одну функцию под названием `wordFilter(words, pref, suff)`, которая строит структуру и отвечает на один запрос сразу.

**Ограничения:**
- `1 <= words.length <= 10^4`
- `1 <= words[i].length <= 7`
- `1 <= pref.length, suff.length <= 7`
- `words[i]`, `pref` и `suff` содержат только строчные английские буквы.
