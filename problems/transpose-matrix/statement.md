Возьмите 2D целочисленную сетку `matrix` и создайте ее зеркальную форму по главной диагонали.

Отражая таким образом, обменивается строками и столбцами позиций каждой записи.

**Ограничения:**

- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 1000`
- `1 <= m * n <= 10^5`
- `-10^9 <= matrix[i][j] <= 10^9`
