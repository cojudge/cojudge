Take a 2D integer grid `matrix` and produce its mirrored form across the main diagonal.

Reflecting in this way exchanges the row and column positions of every entry.

**Constraints:**

- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 1000`
- `1 <= m * n <= 10^5`
- `-10^9 <= matrix[i][j] <= 10^9`
