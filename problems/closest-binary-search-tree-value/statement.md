Учитывая корень двоичного дерева поиска и десятичную цифру `target`, пропущенную в виде строки (например, `"3.714286"`), верните значение дерева, численно наиболее близкое к `target`.

Это переносная адаптация: разберите `target` как двойное и сравните расстояния численно. Когда два значения одинаково близки, верните меньшее.

**Ограничения:**
- `1 <= number of nodes <= 10^4`
- `-10^4 <= Node.val <= 10^4`
- Дерево является действительным двоичным деревом поиска.
- `"-10^5" <= target <= "10^5"` as a decimal string parseable by a double.
