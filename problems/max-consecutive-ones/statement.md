Scan a binary array (only `0`s and `1`s) and report the length of the longest contiguous run of `1`s.

**Example 1:**

```
Input: nums = [1,1,0,1,1,1]
Output: 3
Explanation: The trailing three 1s form the longest run.
```

**Example 2:**

```
Input: nums = [1,0,1,1,0,1]
Output: 2
Explanation: The pair in the middle is the longest run.
```

**Example 3:**

```
Input: nums = [0,0,0]
Output: 0
Explanation: No 1s appear.
```

**Constraints:**

- `1 <= nums.length <= 10^5`
- Each `nums[i]` is `0` or `1`.
