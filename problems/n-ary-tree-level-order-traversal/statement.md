Дерево N-ary позволяет каждому узлу нести любое количество упорядоченных потомков. Здесь дерево прибывает в виде одной строки `data`, используя широтный порядок с `null`, отмечая каждую новую группу братьев и сестер: `[1,null,3,2,4,null,5,6]` означает корень `1` с детьми `3, 2, 4` и `3` с детьми `5, 6`. Пустое дерево `[]`.

Возвратить группировку значений по порядку уровней: список, в котором запись `k` содержит все значения узлов на глубине `k`, начиная с одного корня.

**Ограничения:**
- Node count lies in `[0, 10^4]`.
- Значения узлов — целые числа; высота — максимум 1000.

Адаптация: источник принимает объект N-ary `Node`, который этот судья не может выразить.Поэтому вход представляет собой строку порядка уровня, описанную выше, а выход - `int_list_2d`; разбор происходит внутри ссылки.
