Нарисуйте комбинированный замок с четырьмя круглыми циферблатами, каждый из которых показывает один из циферблатов `'0'` через `'9'`. Циферблат поворачивается мимо оберток `'9'` к `'0'` и поворачивается ниже оберток `'0'` к `'9'`. Одно движение состоит из вращения одного циферблата вперед или назад на одну позицию.

Замок начинается на `'0000'`. Набор `deadends` перечисляет запрещенные коды: наступая на любой из них, блокировка блокируется навсегда. Начиная с начального состояния, не считая его посещением, если он заблокирован, найдите наименьшее количество ходов, которые достигают `target`. Возврат `-1`, когда цель никогда не может быть достигнута безопасно.

**Ограничения:**
- `1 <= deadends.length <= 500`
- `deadends[i].length == 4`
- `target.length == 4`
- `target` не будет в списке `deadends`
- `target` и `deadends[i]` состоят только из цифр.
