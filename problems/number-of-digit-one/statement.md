Учитывая неотрицательное целое число `n`, подсчитайте, сколько раз цифра `1` появляется в каждом целом числе от `0` до `n` включительно.

Например, когда `n` является `13`, цифра `1` отображается в `1`, `10`, `11` (дважды), `12` и `13`, для общего количества случаев `6`.

Возвращайте этот общий счет.

**Ограничения:**
- `0 <= n <= 10^9`
