Для массива `nums` длины `n` представьте, что он вращается по часовой стрелке: последняя запись перемещается в переднюю часть, а каждая другая запись сдвигает один слот вправо. Повторение спина производит `n` аранжировки `arr0 ... arr(n-1)`, где `arr0` является оригиналом. Оцените каждую аранжировку по весовым позициям: `F(k) = 0*arrk[0] + 1*arrk[1] + ... + (n-1)*arrk[n-1]`. Верните самый большой счет среди спинов `n`.

**Ограничения:**
- `1 <= nums.length <= 10^5`
- `-100 <= nums[i] <= 100`
- Ответ помещается в 32-бит подписанного целого числа.

Вычисление каждого балла с нуля стоит квадратичного времени; выведите каждый балл из предыдущего в постоянное время.
