You are given a non-negative integer `n`. Produce an array `ans` with `n + 1` slots, where slot `i` (for each `0 <= i <= n`) stores how many `1` bits occur in the binary form of `i`.

**Example 1:**
```
Input: n = 2
Output: [0,1,1]
```

**Example 2:**
```
Input: n = 5
Output: [0,1,1,2,1,2]
```

**Constraints:**
- `0 <= n <= 10^5`
