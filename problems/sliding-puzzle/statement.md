Вам предоставляется плата `2 x 3`, удерживающая плитки `1` через `5` плюс одна пустая ячейка с пометкой `0`. За один ход вы можете сдвинуть плитку, которая граничит с пустой ячейкой по горизонтали или по вертикали в нее (меняя `0` соседним номером).

Решенный макет - `[[1,2,3],[4,5,0]]`. Начиная с данного `board`, возвращайте наименьшее количество ходов, которые достигают решенного макета, или `-1`, когда он не может быть достигнут.

**Ограничения:**
- `board.length == 2`, `board[i].length == 3`
- `0 <= board[i][j] <= 5`
- Каждое значение появляется ровно один раз.
