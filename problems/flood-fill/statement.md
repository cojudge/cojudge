Вам дается изображение в виде сетки цветовых чисел, стартовой ячейки `(sr, sc)` и нового цветового значения. Перекрасьте стартовую ячейку плюс каждую ячейку, подключенную к ней через общие стороны (вверх, вниз, влево, вправо), которая в настоящее время имеет тот же оригинальный цвет, покрасив все их новым цветом.

Клетки, соединенные только по диагонали, не считаются связанными.Когда новый цвет уже равен цвету исходной клетки, картина остается неизменной.

Верните картинку после перекраски.

**Ограничения:**
- `1 <= image.length, image[i].length <= 50`
- `0 <= image[i][j], color < 65536`
- `0 <= sr < image.length`, `0 <= sc < image[i].length`
