Given a non-negative integer `n`, count how many prime numbers are strictly smaller than `n`. Recall that 0 and 1 are not prime, and a prime has no divisors other than 1 and itself.

**Example 1:**
```
Input: n = 10
Output: 4
Explanation: The primes below 10 are 2, 3, 5 and 7.
```

**Example 2:**
```
Input: n = 0
Output: 0
Explanation: There is nothing below 0.
```

**Example 3:**
```
Input: n = 1
Output: 0
Explanation: 0 is not prime, so the count is 0.
```

**Constraints:**
- `0 <= n <= 5 * 10^6`
