Положительное целое число называется суперуродливым числом, когда каждый простой делитель появляется в заданном списке `primes`. По соглашению, `1` считается суперуродливым числом, поскольку у него вообще нет простых делителей.

Вам дается целое число `n` и строго увеличивающийся массив `primes` простых чисел. Рассмотрим все супер-уродливые числа, построенные из `primes`, отсортированные от наименьшего до самого большого, и верните `n`-е значение в этом порядке (с учетом от 1). Ответ всегда вписывается в 32-бит подписанного целого числа.

**Ограничения:**
- `1 <= n <= 10^5`
- `1 <= primes.length <= 100`
- `2 <= primes[i] <= 1000`
- Каждый `primes[i]` является простым, а значения различаются и сортируются все чаще.
