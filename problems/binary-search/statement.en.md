Given an array of integers `nums` sorted in strictly increasing order and an integer `target`, return the index of `target`. Return `-1` if `target` is not present.

Your algorithm should run in `O(log n)` time.

**Constraints:**

- `1 <= nums.length <= 10^4`
- `-10^4 < nums[i], target < 10^4`
- `nums` is sorted in strictly increasing order.

**Portable interface:** Implement `search(nums, target)` directly. The returned index is zero-based, and no input parsing is required.
