Есть люди `n`, помеченные `0` к `n - 1`. Знаменитость не знает никого, кроме как известна всем остальным. Взаимодействуйте с объектом судьи `relation` — ваш код никогда не получает матрицу смежности:

- `knows(a, b)` возвращает, знает ли человек `a` человека `b`.

Внедряйте `findCelebrity(n, relation)`, возвращающий ярлык знаменитости, или `-1`, когда его нет. Сначала устраните кандидатов в вызовах `O(n)` (если кандидат знает `i`, он не может быть знаменитостью, поэтому перейдите в `i`), затем проверьте, что выживший не знает никого и известен всем. Судья подсчитывает ваши звонки `knows` и сообщает неправильный ответ, если вы превышаете **10 + 5*n** вызовы по тестовому делу (решение `O(n)` использует о `3n`).

Имена методов на языке: Java `relation.knows(a, b)`, Python `relation.knows(a, b)`, C++ `relation.knows(a, b)`, C# `relation.Knows(a, b)`, Rust `relation.knows(a, b)`, Go `relation.Knows(a, b)`, TypeScript `relation.knows(a, b)`, PHP `$relation->knows($a, $b)`.

**Ограничения:**

- `1 <= n <= 100`
- Скрытая матрица `n x n` с записями `0` или `1` (диагональные записи игнорируются).
- В большинстве случаев `10 + 5*n` `knows` вызывается в тестовом случае.
