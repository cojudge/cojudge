Учитывая корень двоичного дерева (сериализированный уровень за уровнем, с `null` для пропавших без вести)
потомки), найти длину, в узлах, самого длинного нисходящего пути, значения которого повышаются
На каждом шагу 1. Путь должен следовать по ссылкам между родителями и детьми. Пустое дерево оценивает 0.

**Ограничения:**
- Дерево находится между узлами 0 и 2000.
- `-10^9 <= node values <= 10^9`.
