Вам предоставляется связанный список в портативной сериализованной форме. Каждый ряд `nodes`
`[value, randomIndex]` для одного узла:

- Узел `i` имеет значение `value`.
- Его указатель `next` нацелен на узел `i + 1` или `null` для конечного узла.
- Его указатель `random` нацелен на узел `randomIndex` или `null`, когда
  `randomIndex` — это `-1`.

Верните ту же структурную кодировку для ** глубокой копии ** списка.
Каждый возвращенный узел должен быть выделен заново, а также указатели `next` и `random`.
Они должны относиться только к скопированным узлам.

Этот интерфейс `int[][]` является переносной адаптацией сериализации обычного интерфейса.
API-интерфейс на основе случайных указателей на узлах, поскольку идентификация объектов не может быть представлена
в возвращаемом значении JSON судья сравнивает серийный список копий
Структура.

**Ограничения:**

- `0 <= nodes.length <= 1000`
- `nodes[i].length == 2`
- `-10^4 <= nodes[i][0] <= 10^4`
- `nodes[i][1] == -1` или `0 <= nodes[i][1] < nodes.length`
