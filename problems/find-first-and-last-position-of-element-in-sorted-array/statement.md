Вы получаете целочисленный массив `nums`, отсортированный в неснижающем порядке, и целочисленный `target`. Найдите первую и последнюю позиции, где появляется `target`, и верните их в виде двухэлементного массива `[first, last]`.

Когда `target` вообще не возникает, возвращайте `[-1, -1]`. Ваш метод должен работать в логарифмическое время, а не сканировать весь массив.

**Ограничения:**
- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `nums` сортируется в неубывающем порядке.
- `-10^9 <= target <= 10^9`
