Вы получаете отсортированный целочисленный массив `nums` плюс три коэффициента `a`, `b`
и `c`. Применить квадратичную карту `f(x) = a*x^2 + b*x + c` к каждому элементу,
Затем возвращайте преобразованные значения в неубывающем порядке.

Прямое преобразование нарушает порядок, но форма параболы позволяет пополнить
Ответ с одного конца: с `a >= 0` самые большие значения приходят извне.
Концы, в то время как с `a < 0` наименьшие значения исходят от внешних концов.

**Ограничения:**
- `1 <= nums.length <= 500`
- `-100 <= nums[i] <= 100`, sorted in non-decreasing order
- `-100 <= a, b, c <= 100`
