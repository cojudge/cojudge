Приведен массив `heights`, где каждое значение представляет собой высоту гистограммной полосы
ширина `1`, возвращает площадь самого большого прямоугольника, который может быть сформирован из одного
или более последовательных баров.

**Ограничения:**

- `1 <= heights.length <= 100000`
- `0 <= heights[i] <= 10000`
