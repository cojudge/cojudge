Создайте кэш наименее часто используемого (LFU) кэша.

`operations[0]` всегда `LFUCache` и `args[0]` удерживает емкость.
Для `i >= 1`, `operations[i]` это `get` с `args[i] = [key]` или `put` с
`args[i] = [key, value]`. Return an array with one entry per `get` operation,
в порядке; `put` не производит вывода. Отсутствующий ключ возвращает `-1`. Когда кэш
Полный, выселить наименее часто используемый ключ, разорвать связи по крайней мере в последнее время
Новый ключ начинается с частоты `1`; каждый `get` или обновление `put`
увеличивает его частоту.

**Ограничения:**

- `1 <= capacity <= 10^4`
- `0 <= key <= 10^5`
- `0 <= value <= 10^9`
