Реализуйте класс `RandomizedSet`:

- `RandomizedSet()` создаёт пустое множество.
- `bool insert(int val)` добавляет `val`, если такого значения нет. Возвращает `true`, если значение добавлено, иначе `false`.
- `bool remove(int val)` удаляет `val`, если оно есть. Возвращает `true`, если значение удалено, иначе `false`.
- `int getRandom()` возвращает случайный элемент текущего множества. Каждый элемент должен выбираться с одинаковой вероятностью. Гарантируется, что при вызове множество не пусто.

Каждый метод должен работать в среднем за O(1).

Используйте имя класса `RandomizedSet`; имя `Solution` зарезервировано проверяющей системой. Конструктор и методы соответствуют оригиналу.

Проверка: результаты `insert` и `remove` точно сравниваются с эталонной моделью. Результат каждого `getRandom` должен принадлежать множеству на момент вызова. Равномерность распределения статистически не проверяется.

**Пример 1:**
```
Вход: operations = ["RandomizedSet","insert","insert","remove"], values = [[],[1],[2],[1]]
Выход: [null,true,true,true]
```
Пояснение: Добавляем новые значения 1 и 2, затем удаляем 1. Все три операции возвращают true.

**Пример 2:**
```
Вход: operations = ["RandomizedSet","insert","insert","remove"], values = [[],[0],[0],[1]]
Выход: [null,true,false,false]
```
Пояснение: Первая вставка 0 возвращает true, повторная — false. Удаление отсутствующего значения 1 возвращает false.

**Пример 3:**
```
Вход: operations = ["RandomizedSet","insert","getRandom","remove"], values = [[],[5],[],[5]]
Выход: [null,true,5,true]
```
Пояснение: В множестве находится только 5, поэтому getRandom возвращает 5. Затем удаление 5 завершается успешно.

**Ограничения:**
- `-2^31 <= val <= 2^31 - 1`
- Не более `2 * 10^5` вызовов `insert`, `remove` и `getRandom`.
- `getRandom` вызывается только для непустого множества.
