Расширяйте соседние ссылки на любое двоичное дерево, а не только на идеальные.

Для каждого узла представьте стрелку к ближайшему узлу на той же глубине справа от него (или ничего, если это последний узел строки). Заполните все такие стрелки по уровню и верните корень.

**Ограничения:**
- `0 <= number of nodes <= 6000`
- `-100 <= Node.val <= 100`

**Примечание по адаптации: ** В первоначальном заявлении используется тип `Node` с полями `left`, `right` и `next`. Этот судья моделирует только `TreeNode` (`val`, `left`, `right`); соседние ссылки не могут быть сериализованы, поэтому решения возвращают то же дерево и сортировка проверяет, что значения и структура сохраняются.
