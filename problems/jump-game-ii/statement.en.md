You are given a nonnegative integer array `nums`. You start at index `0`, and `nums[i]` is the maximum distance you may jump forward from index `i`.

Return the minimum number of jumps needed to reach the last index. Every input is guaranteed to make the last index reachable.

**Constraints:**

- `1 <= nums.length <= 10000`
- `0 <= nums[i] <= 1000`
- The last index is reachable from index `0`.
