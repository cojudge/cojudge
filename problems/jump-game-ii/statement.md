Вы получаете неотрицательный целочисленный массив `nums`Вы начинаете с индекса `0`и `nums[i]` Максимальное расстояние, на которое вы можете перейти от индекса `i`.

Верните минимальное количество прыжков, необходимое для достижения последнего индекса. Каждый вход гарантированно сделает последний индекс доступным.

**Ограничения:**

- `1 <= nums.length <= 10000`
- `0 <= nums[i] <= 1000`
- Последний индекс можно получить из индекса `0`.
