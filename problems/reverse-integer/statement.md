Given a signed 32-bit integer `x`, reverse its decimal digits and return the result.

Preserve the sign, discard leading zeroes in the reversed magnitude, and return `0` if the reversed value falls outside the signed 32-bit range `[-2^31, 2^31 - 1]`. Assume that 64-bit integer storage is available, but arbitrary-precision arithmetic is not needed.

**Constraints:**
- `-2^31 <= x <= 2^31 - 1`
