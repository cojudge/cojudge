Вы начинаете с отсортированного массива `nums` положительных целых чисел и достигаете цели `n`. Используя любое подмножество элементов массива (каждый максимум один раз), вы можете собрать различные суммы. Если каждое целое число от `1` до `n` уже может быть сформировано таким образом, ничего не нужно менять. В противном случае вы можете вставить дополнительные числа («патчи») в любом месте массива. Верните наименьшее количество патчей, которое делает все значения в `[1, n]` репрезентируемыми как суммы подмножества.

**Ограничения:**
- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^4`
- `nums` сортируется в неубывающем порядке.
- `1 <= n <= 2^31 - 1`
