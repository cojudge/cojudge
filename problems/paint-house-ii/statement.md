Рядом находятся дома `n` и `k` с цветами от `0` до `k - 1`. Живопись дома `i` с цветом `j` стоит `costs[i][j]`. Никакие два соседних дома не могут иметь одинаковый цвет.

Возврат наименьшей общей стоимости покраски каждого дома. Когда есть один дом, ответ - просто его самый дешевый цвет.

**Ограничения:**
- `1 <= costs.length <= 100`
- `1 <= costs[i].length <= 100`
- `1 <= costs[i][j] <= 1000`
- Тесты используют по крайней мере два цвета, когда есть более одного дома.
