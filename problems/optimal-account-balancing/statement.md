Каждый вход `transactions[i] = [from, to, amount]` означает, что человек `from` заплатил человеку `to` сумму `amount`.

После всех зарегистрированных переводов группа хочет урегулировать с наименьшим количеством возможных новых платежей (каждый новый платеж может быть любой положительной суммой между любыми двумя людьми).

Возврат минимального количества необходимых расчетных переводов, чтобы все закончили с нулевым чистым балансом.

**Ограничения:**
- `1 <= transactions.length <= 8`
- `0 <= from, to <= 20`, `from != to`
- `1 <= amount <= 100`
