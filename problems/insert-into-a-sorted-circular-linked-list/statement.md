Круглый связанный список отсортирован, когда его значения увеличиваются вокруг кольца, за исключением одной капли от максимума назад к минимуму. Список приведен в виде линейного кодирования `head`, который перечисляет значения в круговом порядке, начиная с текущего головного узла (например, `[3,4,1]` означает `3 -> 4 -> 1 -> 3`). Пустой список - `[]`.

Вставьте новое значение `insertVal`, чтобы кольцо оставалось отсортированным, и верните линейное кодирование, которое начинается с исходной головки (или одно новое значение, когда вход был пустым).

**Ограничения:**
- `0 <= head.length <= 1000`
- `-1000 <= Node.val, insertVal <= 1000`
- Кольцо ввода сортируется в круговом смысле.
- Судья проверяет, что результат начинается с одной и той же головы, содержит все старые значения плюс новые и сортируется по кругу.
