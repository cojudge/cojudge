Есть заборные посты `n` подряд и цвета краски `k`. Подсчитайте способы окраски всех постов, чтобы три последовательных поста не разделяли один цвет.

Внедрить `numWays(n, k)`. Два смежных поста могут иметь общий цвет, но запускать
Три одинаковых цвета запрещены.

**Ограничения:**
- `1 <= n <= 30`
- `1 <= k <= 10`
