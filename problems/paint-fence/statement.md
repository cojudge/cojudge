There are `n` fence posts in a row and `k` paint colors. Count the ways to color all posts so no three consecutive posts share one color.

Implement `numWays(n, k)`. Two adjacent posts may share a color, but a run
of three equal colors is forbidden.

**Examples:**
```
Input: n = 3, k = 2
Output: 6
```
```
Input: n = 1, k = 1
Output: 1
```
```
Input: n = 2, k = 2
Output: 4
```

**Constraints:**
- `1 <= n <= 30`
- `1 <= k <= 10`
