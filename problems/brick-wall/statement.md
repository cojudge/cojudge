Кирпичная стена имеет несколько рядов. Row `i` описывается списком ширины кирпича, общая ширина которого одинакова для каждого ряда. Вы должны нарисовать один прямой вертикальный разрез от верхней части стены до нижней, выбрав положение, которое не находится ни на одном внешнем краю.

Всякий раз, когда разрез проходит через внутреннюю часть кирпича, он считается пересеченным; проход точно вдоль кирпичной границы позволяет избежать пересечения кирпича этого ряда.Верните наименьшее возможное количество пересеченных кирпичей.

**Ограничения:**
- `n == wall.length`
- `1 <= n <= 10^4`
- `1 <= wall[i].length <= 10^4`
- `1 <= sum(wall[i].length) <= 2 * 10^4`
- Каждая строка имеет одинаковую общую ширину
- `1 <= wall[i][j] <= 2^31 - 1`

Примечание по адаптации: оригинальная подпись использует вложенные списки; здесь она смоделирована как `int[][] wall` (`int_array_2d`) с идентичными значениями.
