Given two canonical decimal strings `num1` and `num2`, return their product as a canonical decimal string.

Both inputs represent nonnegative integers. Do not use arbitrary-precision integer libraries, and do not convert either complete input into a built-in integer type.

**Constraints:**
- `1 <= num1.length, num2.length <= 200`
- `num1` and `num2` contain only decimal digits
- Each input has no leading zero unless it is exactly `"0"`
- The returned string must also have no leading zero unless it is `"0"`
