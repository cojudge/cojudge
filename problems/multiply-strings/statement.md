Учитывая две канонические десятичные струны `num1` и `num2`, возвращают свой продукт в виде канонической десятичной струны.

Оба входа представляют собой неотрицательные целые числа.Не используйте целочисленные библиотеки произвольной точности и не преобразуйте ни один из полных входов во встроенный целочисленный тип.

**Ограничения:**
- `1 <= num1.length, num2.length <= 200`
- `num1` и `num2` содержат только десятичные цифры.
- Каждый вход не имеет ведущего нуля, если он не является `"0"`.
- Возвращенная строка также не должна иметь ведущего нуля, если она не `"0"`.
