Вам предоставляется список `nums` с записями `n`, где каждое значение находится между `1` и `n`. Некоторые числа в этом диапазоне появляются дважды, в то время как другие никогда не появляются.

Возвращайте каждое число между `1` и `n`, которое никогда не появляется в `nums`, в порядке возрастания.

**Примечание: ** Оригинальный тип возврата LeetCode - `List<Integer>`; эта проблема использует переносной тип вывода `int_list` с теми же значениями в том же порядке.

**Ограничения:**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= nums.length`
