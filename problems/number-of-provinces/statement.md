Есть города `n` с маркировкой `0` через `n-1`. Квадратная таблица `isConnected` записывает прямые ссылки: запись `[i][j]` - это `1`, когда город `i` подключается прямо к городу `j`, иначе `0`. Ссылки взаимны, и каждый город ссылается на себя.

Города принадлежат к одной и той же провинции, когда они соединяются напрямую или через цепочку промежуточных городов.Считайте, сколько существует отдельных провинций.

**Ограничения:**
- `1 <= n <= 200`
- `n == isConnected.length == isConnected[i].length`
- `isConnected[i][j]` — `0` или `1`
- `isConnected[i][i] == 1` и матрица симметричны
