Возьмем, к примеру, головку отдельно связанной цепи плюс два целых числа `left` и `right`.
с `left <= right`. Переверните порядок узлов с позиции `left`
через положение `right`, оставляя остальные нетронутыми, а затем отдайте назад
головка полной цепи. Позиции узлов отсчитываются от 1 во главе.

**Ограничения:**

- Количество узлов в списке — `n`.
- `1 <= n <= 500`
- `-500 <= Node.val <= 500`
- `1 <= left <= right <= n`
