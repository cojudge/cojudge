Переупорядочение массива в wiggle order: `nums[0] <= nums[1] >= nums[2] <= nums[3] ...`.

**Адаптация: ** Оригинал требует обновления на месте; здесь реализуется
`wiggleSort(nums)` возвращает переупорядоченную копию.
Принято имущество и один и тот же набор ценностей.

**Ограничения:**
- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 10^4`
