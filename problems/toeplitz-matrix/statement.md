Учитывая целочисленную сетку `m x n` `matrix`, решайте, является ли она Toeplitz: каждая диагональ, идущая от верхнего левого к нижнему правому, должна содержать одно повторяющееся значение. Формально каждая ячейка должна равняться своему верхнему левому соседу, когда этот сосед существует.

**Ограничения:**
- `m == matrix.length`, `n == matrix[i].length`
- `1 <= m, n <= 20`
- `0 <= matrix[i][j] <= 99`
