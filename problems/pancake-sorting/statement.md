Блинный флип выбирает положительный `k` и переворачивает первые записи `k` массива. Начиная с `arr` (преобразование `1..n`), возвращает любую последовательность максимум `10 * n` флипов, которая оставляет весь массив отсортированным в неубывающем порядке. Судья переигрывает ваши флипы, поэтому принимается каждая действительная сортировочная последовательность — эталонный ответ является только одной возможностью.

**Ограничения:**
- `1 <= arr.length <= 100`
- `arr` удерживает каждое целое число от `1` до `arr.length` ровно один раз.
- Ответом является целочисленный список с наибольшим количеством записей `10 * arr.length`, каждая из которых находится между `1` и `arr.length`.
