Посмотрите на каждый смежный блок внутри `arr` (блок должен держать соседей вместе и не может быть пустым). Для каждого блока вычислите по битам OR его записей — OR одиночной записи является самой записью.

Сколько различных значений ИЛИ отображается во всех блоках?

**Ограничения:**
- `1 <= arr.length <= 5 * 10^4`
- `0 <= arr[i] <= 10^9`
