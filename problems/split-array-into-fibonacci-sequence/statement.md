Разбейте цифровую строку в список, подобный Фибоначчи.

Список похож на Фибоначчи, когда он содержит по меньшей мере три числа, каждое значение вписывается в подписанное 32-битовое целое число, и каждое число с третьего вперед равняется сумме двух перед ним.Кроме того, ни одно число не может нести ведущий ноль, если само число не является точно нулем.

При наличии строки `num` цифр разделите её на такой список, используя каждый символ ровно один раз в порядке. Возвращайте любой действительный раскол, или пустой список, когда никакой раскол не работает.

**Ограничения:**
- `1 <= num.length <= 200`
- `num` содержит только цифры.
