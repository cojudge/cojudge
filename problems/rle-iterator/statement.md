Кодирование длины пробега сжимает последовательность с интенсивным повторением в пары: для каждого четного индекса `i` `encoding[i]` говорит, сколько копий `encoding[i+1]` появляется дальше.В качестве иллюстрации `[3,8,2,5]` разворачивается до `[8,8,8,5,5]`, и нули могут появляться при пропуске значения.

Каждый вызов `next(n)` потребляет следующие записи `n` и сообщает значение последнего потребленного; когда поток запускается, вызов сообщает `-1` вместо этого.

Чтобы сохранить каждый язык на одной ноге, эта задача объединяет вызовы в одну функцию `runRle(encoding, operations, values)`. Массив `encoding` - это спаренный список выше, `operations[i]` называет вызов (всегда `"next"` здесь), `values[i]` удерживает `n` для этого вызова, а возвращенный массив удерживает ответ каждого вызова в порядке.

**Ограничения:**
- `2 <= encoding.length <= 1000`
- `encoding.length` является четным.
- `0 <= encoding[i] <= 10^9`
- `1 <= n <= 10^9` для каждого вызова `next`.
- В большинстве случаев звонят по `1000`.

**Примечание по адаптации: ** Оригинальная форма LeetCode представляет собой класс `RLEIterator` с конструктором плюс `next(n)`. Здесь аргумент конструктора и последовательность аргументов `next` поставляются вместе в `runRle`, который возвращает список результатов `next`.
