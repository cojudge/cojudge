Take a string `s` and shuffle its characters into a new order in which no two neighbours match.

Produce any such shuffle, or produce `""` when no valid shuffle exists.

**Example 1:**

```
Input: s = "aab"
Output: "aba"
```

**Example 2:**

```
Input: s = "aaab"
Output: ""
```

**Constraints:**

- `1 <= s.length <= 500`
- `s` consists of lowercase English letters.
