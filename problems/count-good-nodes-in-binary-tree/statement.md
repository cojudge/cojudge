Given the root of a binary tree, call a node **good** when no node on the path
from the root to that node has a value greater than the node's value.

Return the number of good nodes in the tree. The root-to-node path includes both
the root and the node itself.

**Constraints:**

- The tree contains between `1` and `100000` nodes.
- `-10^4 <= node.val <= 10^4`
