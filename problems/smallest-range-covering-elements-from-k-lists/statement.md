Вам даны сортированные целочисленные списки `k`. Найдите самый узкий интервал `[a, b]`, который содержит по крайней мере одно число из каждого списка.

Сравните кандидатов по ширине `b - a` в первую очередь; когда ширина ничья, предпочтите меньший старт `a`.

**Ограничения:**
- По крайней мере, один список присутствует; каждый список сортируется все чаще.
- Значения удобно вписываются в диапазон 32-бит.

*Адаптация: вложенные карты ввода в `int_array_2d` и карты ответов на два элемента в `int_array` в этом решении, хотя в естественном заявлении используются списки списков.
