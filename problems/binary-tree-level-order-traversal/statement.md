Начиная с `root` двоичного дерева, собирайте значения узла по одному горизонтальному слою за раз: сначала корневой слой, затем его потомки слева направо, затем следующая глубина слева направо и так далее.Верните эти слои в виде вложенных списков.

**Ограничения:**

- Количество узлов в дереве находится в диапазоне [0, 2000].
- -1000 ≤ Node.val ≤ 1000
