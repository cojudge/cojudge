Вы наблюдаете поток неотрицательных целых чисел по одному за раз.
Прибытия, которые вы хотите компактное резюме: набор различных значений, наблюдаемых до сих пор,
написанный как сортированный список разъединенных закрытых интервалов, который охватывает именно те
ценностей.

Два значения относятся к одному и тому же интервалу, когда все между ними имеет также
Например, видя `1, 3, 7, 2, 6` покидает крытый набор
`{1, 2, 3, 6, 7}`, сокращенно `[[1, 3], [6, 7]]`.

**Примечание по адаптации: ** Вместо государственного класса реализуйте единую функцию
`runSummaryRanges(values)`, который потребляет всю последовательность прибытия и возвращается
заключительные краткие интервалы, отсортированные по началу.

**Ограничения:**
- `0 <= values.length <= 10000`
- `0 <= values[i] <= 10000`
- Ценности могут повторяться; повторы ничего не меняют.
