Учитывая строку `s` из прописных английских букв, посмотрите на каждую смежную подстроку (включая всю строку и каждый отдельный символ). Для одной подстроки ее счет - это количество символов, которые встречаются точно один раз внутри нее. Сложите оценки всех подстроек и верните общий модуль `10^9 + 7`.

**Ограничения:**
- `1 <= s.length <= 10^5`
- `s` состоит только из английских букв.
