Прогуляйтесь по двоичному дереву по уровню, но чередуйте направление чтения на каждой строке: первая строка идет слева направо, следующая идет справа налево, затем снова слева направо и так далее.

Соберите значения узлов на каждой глубине в порядке посещения, переверните строки, которые попадают на нечетные глубины, и верните все строки сверху вниз.

**Ограничения:**
- `0 <= number of nodes <= 2000`
- `-100 <= Node.val <= 100`

**Примечание по адаптации: ** Список вложенных значений представлен как `int_list_2d`.
