Предоставляется указатель на одну вершину **связанной ненаправленной** сети.

Производить независимую копию (**твердую копию**) всей сети.

Каждая вершина хранит целую полезную нагрузку (`int`) вместе с каталогом смежности.

Джава
Классный узел {
    публичный вал;
    публичные соседи List<Node>;
}
```

** Макет оценки:**

Чтобы корпуса были компактными, пиковые полезные нагрузки совпадают с порядковыми вершинами (на основе 1).
`adjList` представляет собой двумерный список, в котором `adjList[i]` перечисляет каждого соседа вершины `i` (на основе 1).
`adjList[i]` не поставляется в любом гарантированном заказе.

В рутине принимается указатель на начальную вершину сети (`Node`, `val = 1`).
Он должен передать указатель на аналог этой открывающейся вершины внутри дублированной сети.

**Ограничения:**
- Количество узлов в графе находится в диапазоне `[0, 100]`.
- `1 <= Node.val <= 100`
- `Node.val` уникален для каждого узла.
- На графике нет повторяющихся краев и нет самоподъемов.
- Граф подключен, и все узлы могут быть посещены, начиная с данного узла.
