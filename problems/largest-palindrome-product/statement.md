Для заданного числа цифр `n` посмотрите на все продукты с двумя цифрами `n` (от `10^(n-1)` до `10^n - 1`, с `1..9` для `n = 1`). Среди этих продуктов выберите самый большой, чья десятичная запись читается одинаково вперед и назад.

Поскольку этот палиндром может быть огромным, верните его по модулю `1337`.

**Ограничения:**

- `1 <= n <= 8`
