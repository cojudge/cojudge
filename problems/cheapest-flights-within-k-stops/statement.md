Есть города `n` с маркировкой от `0` до `n - 1`.
`flights[i] = [from, to, price]` имеет указанную стоимость билета.

Верните самую дешевую цену на маршрут от `src` до `dst`, который использует максимум.
Промежуточные остановки `k`. Возврат `-1`, если такого маршрута не существует.

**Ограничения:**

- `2 <= n <= 100`
- `0 <= flights.length <= n * (n - 1) / 2`
- `flights[i].length == 3`
- `0 <= from, to, src, dst < n`
- `from != to` и `src != dst`
- `1 <= price <= 10^4`
- `0 <= k < n`
- Не существует дублирующих прямых рейсов.
