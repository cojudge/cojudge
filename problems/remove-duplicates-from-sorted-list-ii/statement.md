Учитывая заголовок сортированного связанного списка, удаляйте каждый узел, значение которого происходит более одного раза, сохраняя только узлы с полностью уникальными значениями.Остальные узлы остаются в своем первоначальном относительном порядке.

Например, прогон, подобный `2 -> 2 -> 2`, полностью исчезает, при этом сохраняется изолированное значение. Верните заголовок обрезанного списка.

**Ограничения:**
- `0 <= number of nodes <= 300`
- `-100 <= node value <= 100`
- Список отсортирован в неубывающем порядке.
